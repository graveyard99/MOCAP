# Example configuration

`synthetic-project.yaml` records the real schema and calibrated eight-camera geometric fixture. These transforms are synthetic and must never be reused as guessed calibration for a real shoot. It expects the matching `observations.json` and `media/` generated by `openmocap demo --output outputs/demo --cameras 8 --frames 36`. The generated project.yaml also retains frame manifests and stage/cache metadata, so use that file for processing/review.

For real capture, use the New Project wizard or `openmocap project init`, import measured camera calibration and actual timestamped observations/compatible inference assets, then run the resulting project.yaml. New project camera geometry and metric scale are deliberately unspecified.
