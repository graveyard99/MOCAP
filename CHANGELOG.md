# Changelog

## 0.1.0 — engineering preview

- Metric camera models, arbitrary-N robust triangulation, continuous asynchronous reconstruction and affine clocks.
- Persistent actor rig/shape, NumPy SMPL-family coefficient adapter, explicit technical fixture and confidence-governed fitting.
- Four floor-aware contacts, bounded optional kinematic refinement and inspectable QC.

- Local Qt project manager, wizard, shared-service background jobs, viewers, camera editors, manual overrides and export controls.
- Isolated bootstrap, deterministic lock, launchers, CI, synthetic acceptance fixtures and operator manual.

This preview does not claim production real-capture validation or completion of every requested advanced tool. See `docs/BUILD_STATUS.md`.
